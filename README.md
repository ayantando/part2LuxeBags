# LUXE BAGS Website

A simple multi-page website for **LUXE BAGS**, a fictional luxury handbag brand. Tagline: *"Be a Dreamer — Be LUXE"*.

## Description

This project showcases a handbag storefront including a homepage with featured products, an about section, and pages for browsing, cart, checkout, and contact. The design uses a navy, beige, and brown color palette to reflect the brand's aesthetic.

## Project Structure

```
/
├── index.html          # Homepage
├── about us.html        # About page
├── catalogue.html       # Shop / product catalogue
├── cart.html            # Shopping cart
├── checkout.html        # Checkout page
├── contact.html         # Contact page
├── css/
│   └── style.css        # Stylesheet (linked, not yet included)
└── Images/
    ├── image1.webp       # Barbie TINGZ handbag
    ├── image 2.webp      # Ted Tote handbag
    └── Tote bag.webp     # Navy Dindy tote bag
```

## Pages

| Page | File | Description |

| Shop | `catalogue.html` | Full product catalogue |
| Cart | `cart.html` | Shopping cart view |

| Contact | `contact.html` | Contact details and form |

## Setup

1. Clone or download this repository.
2. Make sure `css/style.css` is present in a `css/` folder alongside `index.html` (the stylesheet is currently linked via a local path and will need to be updated to a relative path, e.g. `css/style.css`, for the site to render correctly outside the original development machine).
3. Ensure the `Images/` folder contains the product images referenced in the HTML.
4. Open `index.html` in a browser to view the site.
